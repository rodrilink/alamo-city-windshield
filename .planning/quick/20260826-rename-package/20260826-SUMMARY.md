# Summary: Rename the project package

## What changed

The npm package was still called `nextjs-scaffold`, a leftover from the initial
Next.js scaffold. It is now `alamo-windshield-landing-page`.

| File | Change |
|------|--------|
| `package.json` | `name` field |
| `package-lock.json` | root `name` and `packages[""].name` |

Both manifests must agree or `npm ci` warns about a mismatched lockfile, so all
three occurrences were changed together.

## Deliberately unchanged

- **`.planning/phases/01-foundation/01-01-SUMMARY.md`** mentions
  `/tmp/nextjs-scaffold` as a record of how the project was originally
  scaffolded. That is an accurate account of a past event, not a live
  reference — rewriting it would falsify the historical record.
- **User-facing branding needed nothing.** `SITE_NAME` (root layout metadata)
  and `BUSINESS.name` already read "Alamo City Windshield Repair". This change
  is the package identifier only; nothing visible to visitors moved.
