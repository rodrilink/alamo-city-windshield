# Quick Task: Rename component files to kebab-case

## Problem

32 files under `src/components/` are PascalCase (`HeroSection.tsx`,
`TopNav.tsx`, …) while the rest of `src/` is already lowercase. 44 import
specifiers reference them by the PascalCase path.

## Decision (from discussion)

Scope is **component filenames only**:

- Rename the 32 `.tsx` files to kebab-case.
- Rewrite the 44 `@/components/...` import specifiers to match.
- **Exported symbols stay PascalCase.** `HeroSection`, `TopNav`, etc. remain
  the component names. Renaming them to lowercase would break React: JSX
  treats a lowercase tag as a DOM element, so `<heroSection />` would silently
  render an unknown HTML element instead of the component. The user chose this
  scope explicitly.
- `.planning/` docs are out of scope.

## Critical hazard: `core.ignorecase=true`

This repo is on Windows with `core.ignorecase=true`. A direct
`git mv HeroSection.tsx hero-section.tsx` is a no-op that git may not record,
leaving the index holding the old name while the worktree holds the new one —
which then breaks on case-sensitive CI/Vercel (Linux) even though it builds
locally.

Every rename MUST therefore go through a two-step temp name:

```
git mv HeroSection.tsx __tmp__ && git mv __tmp__ hero-section.tsx
```

Verification must confirm git recorded 32 `R` (rename) entries, not fewer.

## Tasks

### T-1: Rename the 32 files via two-step `git mv`

**Files:** all 32 PascalCase `.tsx` files under `src/components/`

**Action:** For each, derive the kebab name by inserting `-` at each
lowercase→uppercase boundary and lowercasing, then two-step `git mv`. The
mapping was pre-computed and verified collision-free.

**Verify:** `git status --porcelain` shows exactly 32 renames; no PascalCase
basename remains under `src/`.

**Done:** All 32 files renamed and staged as renames.

### T-2: Rewrite the 44 import specifiers

**Files:** every `.ts`/`.tsx` under `src/` that imports a renamed component

**Action:** For each old→new basename pair, replace the trailing path segment
in `@/components/.../OldName` specifiers with the kebab name. Only the final
segment changes — directory names (`admin-users`, `layout`) are already
lowercase and must not be touched.

Also check for any relative (`./OldName`, `../OldName`) imports between
sibling components, not just `@/` aliased ones.

**Verify:** zero remaining `@/components/...` specifiers containing an
uppercase letter after the last `/`.

**Done:** Every import resolves to the new filename.

### T-3: Verify the full gate

**Action:** `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build`.
TypeScript resolution is the real proof here — a missed import is a hard
compile error, not a silent failure.

Additionally confirm the recorded rename count and that no file's *content*
changed apart from import lines.

**Verify:** all four green; `git diff --cached --stat` shows only import-line
churn beyond the renames.

**Done:** Build passes and route table is unchanged.

## Must-haves

- All 32 renames recorded by git as renames (`R`), not delete+add, and not
  silently skipped by `core.ignorecase`.
- No PascalCase basename left under `src/`.
- Exported component symbols unchanged (still PascalCase).
- No directory renamed.
- `tsc`, `lint`, `test`, `build` all pass.
