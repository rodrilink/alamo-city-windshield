# Quick Task: Remove stale Phase 6 copy from the dashboard

## Problem

The Visitors summary card renders "Tracking starts in Phase 6". Phase 6 shipped
2026-08-07 and was runtime-verified — all four event types confirmed writing to
`analytics_events`. The hint is not merely outdated:

- It is **unconditional** (`showTrackingHint: true`), so it renders underneath a
  real non-zero count, implying a live number is provisional.
- It leaks internal project phase numbering into an operator-facing UI.

The same staleness exists in a second user-facing string and four code comments.

## Scope

**User-facing copy (2 strings):**

- `trackingStartsHint: 'Tracking starts in Phase 6'` — removed entirely
- `dashboardEmptyStateHint: 'No data yet — event tracking arrives in Phase 6.'`
  — reworded; a chart still needs an honest empty state for a genuinely quiet
  window

**Stale code comments (4 sites)** that assert tracking is not yet wired:
`summary-cards.tsx` docblock, `visitors-chart.tsx`, `vin-search-chart.tsx`,
`bucket-by-day.ts`.

## Decision (from discussion)

Drop the card hint entirely — Visitors and VIN searches become plain counts like
Contacts and Bookings. Rejected: keeping a zero-only hint, and rewording the
always-on hint (both retain a caveat the data no longer justifies).

## Tasks

### T-1: Remove the card hint

**Files:** `src/components/dashboard/summary-cards.tsx`, `src/lib/constants.ts`

Remove `showTrackingHint` from the interface and all four card definitions,
remove the conditional render, delete `trackingStartsHint`, and rewrite the
now-false D-02 docblock paragraph to record that D-02 is superseded and why.
Collapse the fragment left holding a single child.

### T-2: Reword the chart empty state

**Files:** `src/lib/constants.ts`

`dashboardEmptyStateHint` must describe the window being empty, not a pending
feature — a "coming soon" string would hide a genuinely quiet period or a
broken writer.

### T-3: Correct the four stale comments

**Files:** `visitors-chart.tsx`, `vin-search-chart.tsx`, `bucket-by-day.ts`

They claim the empty state "is what renders today" and that every day is
currently zero. Both are false post-Phase-6.

### T-4: Verify

`tsc --noEmit`, `lint`, `test`, `build`; confirm no stale string survives in
shipped output.

- All four gates pass.
