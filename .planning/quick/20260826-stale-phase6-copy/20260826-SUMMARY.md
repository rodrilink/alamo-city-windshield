# Summary: Remove stale Phase 6 copy from the dashboard

## What changed

The Visitors card read "Tracking starts in Phase 6". Phase 6 shipped 2026-08-07
and was runtime-verified, so the hint was wrong — and worse than merely
outdated: it was unconditional, rendering underneath a real non-zero count and
implying a live number was provisional. It also leaked internal phase numbering
into an operator-facing UI.

Investigating turned up the same staleness in five more places, not just the
one card.

| File | Change |
|------|--------|
| `src/lib/constants.ts` | Deleted `trackingStartsHint`; reworded `dashboardEmptyStateHint` to "No activity recorded in this period." |
| `src/components/dashboard/summary-cards.tsx` | Removed `showTrackingHint` from the interface and all four card definitions, removed the conditional render, collapsed the leftover single-child fragment, rewrote the D-02 docblock |
| `src/components/dashboard/visitors-chart.tsx` | Docblock claimed "the empty state, not the bar chart, is what renders today" — false post-Phase-6 |
| `src/components/dashboard/vin-search-chart.tsx` | Same stale claim |
| `src/lib/analytics/bucket-by-day.ts` | Comment claimed "every day is currently a zero day" |

## Decisions

- **Dropped the card hint entirely** rather than keeping a zero-only variant or
  rewording the always-on one. Tracking is live and verified, so any caveat
  under those numbers asserts something untrue. Visitors and VIN searches are
  now plain counts, identical in treatment to Contacts and Bookings.
- **Kept an empty state on the charts, reworded.** A chart still needs to say
  something when a window genuinely has no rows. The new wording describes the
  window rather than promising a pending feature — a "coming soon" string there
  would hide either a legitimately quiet period or a broken writer.
- **D-02 is recorded as superseded, not silently deleted.** The docblock
  explains what the hint was and why it is gone, so the asymmetry it originally
  protected is not reintroduced by someone later "fixing" the inconsistency.
