**Next.js 15 dynamic `params` is a Promise.** The second argument's `params` must be typed `Promise<{ vin: string }>` and awaited. This changed in Next.js 15.0.0-RC; the installed version is 15.5.15. Source: nextjs.org/docs/app/api-reference/file-conventions/route version-history table.

**GET Route Handlers are uncached by default in Next.js 15.** No `export const dynamic = 'force-dynamic'` and no `export const revalidate` is needed. Do NOT add `next: { revalidate: N }` to the outbound `fetch` — this phase caches exclusively via `vin_cache` per D-21, and a Next Data Cache layer on top would have different invalidation semantics with no way to bypass it from application code. The "add `revalidate` caching" line in `.planning/research/ARCHITECTURE.md` (line 396) predates D-21 and is superseded — do not follow it.

**Only `NextResponse` has an established precedent in this project.** `src/lib/supabase/middleware.ts` is the only existing file that touches `NextRequest`/`NextResponse`. Mirror its inline "why this branch exists" commenting style — for example its line 41 comment `// CRITICAL: getUser() not getSession() — revalidates JWT server-side (CVE-2025-29927)`. Apply that style to each of the four status branches, explaining which decision the branch serves.

**Verified live test VINs for the acceptance checks:**
- `1FTFW1E85NFA12345` → NHTSA returns HTTP 200 with `ErrorCode: "1"`, `ModelYear: "2022"`, `Make: "FORD"`, `Model: "F-150"`, `BodyClass: "Pickup"`. Expected handler result: `status: "decoded"`, `vehicle.sizeBucket: "suv-truck"`, `adasApplies: true`.
- `ZZZZZZZZZZZZZZZZZ` → 17 valid VIN characters, so it passes format validation, but NHTSA returns all-empty core fields. Expected handler result: `status: "not-found"`, and **no `vin_cache` row written**.
- `short` → fails format validation. Expected: HTTP 400 with `status: "invalid"`, and no outbound NHTSA call and no database query.

**Response contract** — both bodies are defined in `src/types/vehicle.ts` (plan `03-02`): `VinLookupResponse` has `status`, `vehicle`, `estimates`, `adasApplies`, `cached`. `ManualEstimateResponse` has `status`, `modelYear`, `estimates`, `adasApplies`.

**`vin_cache.model_year` is a TEXT column.** A cache hit returns it as a string and it must be `Number.parseInt`-ed before use.

**Bucket re-derivation on a cache hit.** `vin_cache` stores `body_class` but not the derived bucket, so a cache hit must call `mapBodyClassToSizeBucket` again. This is intentional: it means a future correction to the mapping table applies to already-cached VINs without a cache flush, and it keeps the D-19 branch reachable from the cache path.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → `GET /api/vin/[vin]` | Unauthenticated by design. A fully user-controlled path segment flows into an outbound URL and a database filter. |
| public internet → `GET /api/estimate` | Unauthenticated by design. A user-controlled query parameter drives a computation. |
