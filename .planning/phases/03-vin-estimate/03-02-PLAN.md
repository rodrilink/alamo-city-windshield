<objective>
Establish the two pieces every other plan in this phase depends on: a working test harness, and the shared type contract for the VIN lookup and estimate responses.

Purpose: The response contract must exist and be explicit **before** the Route Handler and the UI are built, so neither side has to go on a scavenger hunt to discover the other's shape. The contract is also the mechanism that satisfies D-15 — because the response carries every precomputed glass variant, the browser gets numbers instead of a formula. The test harness exists because the six locked D-06 fixtures are this phase's only objective proof the pricing formula is right, and there is currently no test runner in the repository at all.

Output: `vitest.config.mts`, `src/test/server-only-stub.ts`, `src/types/vehicle.ts`, and `npm test` / `npm run test:watch` scripts.
</objective>
