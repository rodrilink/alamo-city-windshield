<objective>
Build the single server-side read module every dashboard surface consumes: four card totals (D-02 mixed-source), three chart series (D-01 and D-18), and two bounded tables (D-16).

Output: one new module with six exported read functions, the two D-16 limit constants, and a clean type-check and lint.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Session cookie → SSR Supabase client → Postgres RLS | Every dashboard read executes with the logged-in admin's JWT, so RLS is the enforcing control, not application logic |
| Postgres rows → RSC payload → browser | Selected columns are serialized into the page payload and reach the browser |
