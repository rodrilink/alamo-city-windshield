<objective>
Build the `/book` route: the month calendar, the per-date slot list, the booking form wired to the `createBooking` Server Action, and the confirmation screen.

Purpose: This assembles everything the previous plans produced into the user-facing booking flow. It is also where D-19's trust rule is enforced at the page level — only the 17-character VIN travels in the URL, and `/book` re-decodes it server-side to build `vehicle_desc`, because an attacker-controlled vehicle description would be written to the database and later rendered in Phase 5's admin table.

D-20 is load-bearing here: `/book` uses normal-flow chrome, not snap-scroll. A calendar plus slot list plus form is precisely the taller-than-viewport content that caused the Phase 3 clipping bug (03-UAT test 14).

Output: the `/book` page and its four components, plus a thin Server Action for the on-select availability re-fetch.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL search param → server-side decode | `?vin=` is fully attacker-controlled |
| server props → Client Component | Only precomputed, non-secret data may cross |
| browser clock → disabled-date decision | The client must never decide what "past" means |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06-01 | Tampering / Spoofing | Attacker-controlled `vehicle_desc` or pricing supplied via the URL | mitigate | D-19: only the 17-char VIN travels in `?vin=`, gated by `isValidVin`; `/book` re-decodes server-side via `readVinCache`/`decodeVin` to build `vehicle_desc`. Asserted by a grep proving `vehicle_desc` is never read from search params. |
| T-04-06-02 | Tampering | Manipulated browser clock re-enabling a passed date or slot | mitigate | D-06: the server computes Central-time "today" with `getBusinessNowParts()` and passes it down; the `disabled` matcher compares against that value, never `new Date()` on the client |
| T-04-06-03 | Information Disclosure | Pricing formula reaching the browser via a Client Component import | mitigate | The Phase 3 `server-only` fence on `@/lib/pricing` remains; acceptance criteria grep asserts no booking component imports it, and the fence makes any such import a build error |
