## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local filesystem → git remote | A service-role key written to a tracked file would be published to the repository host |
| Next.js server bundle → browser bundle | Any `NEXT_PUBLIC_`-prefixed variable is inlined into client JavaScript and readable by every visitor |
| application → Supabase Postgres | The service-role key authenticates as a role that bypasses all row-level security |
