<objective>
Close code-review warning WR-03: add maximum-length validation to every public free-text
field in both the booking and contact Zod schemas.

Purpose: `createBooking` and `createContact` are public, unauthenticated `'use server'`
endpoints. A scripted POST that never touches the React form can currently submit
arbitrarily large strings into unbounded Postgres `TEXT` columns — a storage/bandwidth
amplification vector against the free-tier database. The Server Actions already
re-validate with `safeParse`, so a schema-level cap is enforced against direct POSTs,
not merely against the browser form.

Output: `.max()` bounds on both schemas plus unit tests pinning the boundaries.
</objective>
